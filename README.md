# 振り返りポータル — 体験版（デモ）

授業の「目標設定」と「振り返り」に特化した、教員向けの無料Webアプリの体験版です。

- **ログイン不要**：URLを開くだけで、先生の画面・生徒の画面の両方を試せます。
- **どこにも保存されません**：入力した内容はブラウザの中だけで動き、ページを開き直すと元に戻ります。
- 表示されている生徒名・振り返りは、すべて**架空のサンプル**です。

## 試せること

- 目標と振り返り（単元・第N時を選ぶと「本時のゴール」が表示されます）
- みんなの振り返り
- 一括返信（生徒の実名をAIに送らない設計）
- 管理者画面（単元マスタ・名簿・目標の選択肢／テストモードで生徒の画面に切り替え）

## 本番で使いたい方へ

本番版は Google Apps Script として動き、データは**先生ご自身のGoogleアカウントの中だけ**に保存されます。
導入手順は配布記事をご覧ください。
